# Presentation Layer
- <mark style="background: #ADCCFFA6;">Keywords:</mark>
	- <mark style="background: #ADCCFFA6;">Data formatting</mark>
	- <mark style="background: #ADCCFFA6;">Encryption</mark>
- Formats the data to be exchanged and secures that data with proper encryption
## Data Formatting
- Data is formatted by the computer to have compatibility between different devices
- Examples:
	- ASCII (American Standard Code for Information Interchange)
		- Text-based language to use
	- GIF
	- JPG
	- PNG
- Ensures data is readable by the receiving system
- Provides proper data structures
- [[Layer 7 (Application)|Negotiates data transfer syntax for the Application Layer (Layer 7)]]
## Encryption
- Used to scramble the data in transit to keep it secure from prying eyes and provide data confidentiality
- Examples:
	- TLS (Transport Layer Security)
## Devices and Protocols
- Scripting languages
	- HTML, XML, PHP, Javascript
		- Formats data
- Standard text
	- ASCII, Unicode, EBCDIC
- Pictures
	- GIFs, JPGs, etc.
- Movie files
	- MP4, MPEG, MKV
- Audio file
	- MP3, FLAC
- Encryption algorithms
	- TLS, SSL
