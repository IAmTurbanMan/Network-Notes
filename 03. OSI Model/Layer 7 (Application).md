# Application Layer
- Provides application-level services where users communicate with the computer
- Not talking about Apps we use to interface, like Outlook or Gmail
	- Low level protocols, like POP3, IMAP, and SMTP for email
## Application Services
- Unites communication components from more than one network application
## Service Advertisement
- Sending out of announcements to other devices on the network to state the services they offer
- Printer that sits on a network
	- Will scream at new devices connecting to the network that it can print things
## Devices and Protocols
- Email applications
	- POP3, IMAP, SMTP
- Web browsing
	- HTTP, HTTPS
- DNS
- File transfer protocols
	- FTP, FTPS, SFTP
- Remote access
	- TelNET, SSH, SNMP
