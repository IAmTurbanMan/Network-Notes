> Explain important factors of physical installations.

## Wet Pipe Systems
- Most basic type of fire suppression system that involves using a sprinkler system and pipes that always contain water
- Avoid using wet pipe system in and around data centers
## Pre-action Systems
- Helps minimize the risk of accidental releases when using a wet pipe system
## Special Suppression Systems
- Utilizes a clean agent as part of its suppression system
	- Halo-carbon agent or inert gas
	- When agent or inert gas is released it will displace the oxygen in the room and starve the fire
- Any facility that utilizes this must be equipped with an alarm that announces whenever the clean agent is going to be released
	- Also must have supplemental oxygen available
