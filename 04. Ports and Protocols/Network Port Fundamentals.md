# Port
- A logical opening in a computer that represents a service or application
- Numbered from 0 to 65,535
- IP address is building, Port is the room within the building
## Well-known ports
- 0 to 1,023
- FTP, SMTP, HTTP, HTTPS
- Registered with IANA (Internet Assigned Numbers Authority)
## Registered Ports
- 1,024 to 49,151
- Registered with IANA
## Ephemeral Ports
- 49,152 - 65,535
- Short-lived temporary ports which are opened for just a small period of time from a predefined range of ports
- AKA
	- Dynamic ports and Private ports
	- Can be used by anyone or any system without having to register them
