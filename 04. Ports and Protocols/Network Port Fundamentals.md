# Port
- A logical opening in a computer that represents a service or application
- Numbered from 0 to 65,535
## Well-known ports
- 0 to 1,023
- FTP, SMTP, HTTP, HTTPS
- Registered with IANA (Internet Assigned Numbers Authority)
## Registered Ports
- 1,024 to 49,151
- Registered with IANA
