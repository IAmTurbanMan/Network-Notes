> Compare and contrast networking appliances, applications, and functions.

### Client/Server Model
- Utilizes a dedicated server to provide access to network resources
	- files, scanners, printers, etc.
- Admin and backup are easier
	- One central place where all resources live (server)
- Bennies
	- Centralized admin
		- One or a few key servers
		- Focus all attention on those
	- Easier management
	- Better scalability
- Drawbacks
	- Costs more
		- Requires dedicated hardware
	- Requires dedicated OS
	- Requires specialized skill-set
### Peer-to-Peer Model
- Peers or other machines (laptops, desktops) can share resources together directly
- Where is this useful?
	- File sharing and torrenting
- Bennies
	- Lower cost
		- no dedicated hardware or infrastructure
	- No specialized OS
	- No dedicated resources
- Drawbacks
	- If machine is off, peers cannot access anything
	- Decentralized management
	- Inefficient for large networks
	- Poor scalability
