> Given a scenario, select and configure wireless devices and technologies.

### Infrastructure Mode
- Most common type of wireless mode that uses a wireless access point as a centralized point
- Most definitely using this at home
### Ad Hoc Mode
- Decentralized wireless network which creates peer-to-peer connections and does not require a router or access point
### Wireless Mesh Topology
- An interconnection of different types of nodes, devices, and radios
- Use different radio techs
	- Bluetooth, Wi-Fi, Microwave, Cellular, Satellite
		- Two+ technologies are combined to create wireless mesh network
- Gives redundant network for use in harsh environments
- When and where?
	- After hurricane, humanitarian assistance uses wireless mesh topologies to communicate with people
