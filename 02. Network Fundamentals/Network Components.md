> Compare and contrast networking appliances, applications, and functions.
### Clients
- Workstations
- Laptops
- Tablets
- Smartphones
- TVs
- IoT devices
### Servers
- Email
- File
- Web
- Media
- Can exist on dedicated hardware or specialized software
### Hubs
- Older tech
- Limitations
	- Increased network errors due to their broadcasting nature
### Switches
- Connect network devices and only forward traffic from one port to intended destination port
	- Avoid unnecessary broadcasting of data over the network
### WAPs/APs
- Used to broadcast data over radio frequency
### Routers
- Make intelligent forwarding decisions based on the IP addresses of the different clients, servers, or other devices that are communicating over the network
- Modern routers predominantly rely on the Internet Protocol to route the traffic across the network
### Firewalls
- Monitor and control incoming and outgoing network traffic based on predetermined security rules by using ACLs
- Protect network from outside threats
- Can be hardware based, software based, or a combo of both
### Load Balancers
- Prevent any one server from becoming a bottleneck
- Improves overall network performance
### Proxy
- Functions
	- Web filtering
	- Shared network connections
	- Data caching
	- Enhanced security and privacy
		- Hides user's real IP address
		- Limits exposure to the internet
### IDS
- Detects and alerts
### IPS
- Detects and prevents
### Controllers
- Enables network admins to dictate the behavior or network switches and routers through software
### NAS Device
- Connected to network
- Allow for data storage/retrieval from a central location
### SAN
- Handle large volumes of data
- Enhance storage devices like disc arrays and tape libraries and make them accessible to servers
### Media
- Copper cable
- Ethernet cable
- Fiber optic cable
- Wireless signals
### WAN Link
- Essential for global connectivity
